## 1. 这是什么

Switch Dev 是一个运行在你本机的代理 + 桌面面板。它把你已经登录的 AI 编程工具（JoyCode / DevEco Code / WorkBuddy）以及你自行配置的任意 OpenAI / Anthropic 兼容 API，统一搬运成标准接口：

```
 Anthropic /v1/messages       ─┐
 OpenAI   /v1/chat/completions ─┼─►  127.0.0.1:8787  ─►  各模型上游
 OpenAI   /v1/responses        ─┘
```

Claude Code、Codex、cc-switch 等客户端只需把 `baseURL` 指向本地，就能用上所有这些模型。它本身**不提供模型、不签发 Token、不经转任何第三方服务器**——请求从你本机出发，用你的登录态，直达各家官方接口。

## 2. 安装与启动

### 前置条件

至少有一个可用的模型来源：

| 来源 | 前置条件 |
|------|---------|
| **JoyCode** | 安装并扫码登录 JoyCode 客户端，确认客户端内能正常对话 |
| **DevEco Code** | ⚠️ 先[注册华为开发者账号并完成实名认证](https://developer.huawei.com)，`npm i -g @deveco/deveco-code` 后执行 `deveco auth login`，确认能正常调用模型 |
| **WorkBuddy** | 安装并登录 WorkBuddy 客户端，确认内能正常对话 |
| **自定义供应商** | 持有任意 OpenAI / Anthropic 兼容服务的 API Key |

> OpenCode 不再作为内置登录态上游，统一通过「供应商」页用 API Key 方式接入。

### 启动

```bash
./bin/switch-dev          # macOS / Linux
# Windows 双击 switch-dev.exe
```

启动后：

- 代理服务监听 `127.0.0.1:8787`；
- 托盘出现图标，窗口可关闭（应用继续在后台运行）；
- 首次启动会自动生成接入 apiKey 并写入配置目录。

**代理控制卡片**
- 状态圆点：绿色 = 运行中，红色 = 已停止。

- **链长**：auto 模式下当前降级链包含的模型数。

- 当所有内置上游凭据都无效时，顶部出现黄色提示条，引导前往「凭据」页安装登录。

**今日概览**
- **今日消耗 Token**：输入 + 输出总量。
- **今日消耗费用**：按费率库估算的美元成本（仅估算，实际以各平台为准）。
- **今日输出速率**：按 token 加权的平均输出速度。
- 下方表格按模型列出今日输出速率排名，前三带有奖牌图标。

## 5. 供应商

「供应商」页管理你自行接入的 API 服务。这些供应商的模型与内置上游平级，可以加入降级链、参与路由。

### 5.1 添加供应商

点右上角 **「+ 新增」** 展开编辑表单。有两种来源：

```
┌─ 来源 ──────────────────────────────────────┐
│ ○ 从内置目录选   ○ 自定义添加               │
└─────────────────────────────────────────────┘
```

**从内置目录选（推荐）**
1. 在下拉框搜索供应商名称（支持名称 / id / baseURL / 模型名检索）。
2. 可用标签筛选：
   - 地区：国际 / 国内
   - 是否需要信用卡
   - 上下文规模：<128K / 128K–1M / ≥1M
   - 模型数量
3. 选中后自动填充名称、BaseURL、候选免费模型列表，并显示「获取 API Key」外链。
4. 填入你的 API Key，点「拉取模型」。

**自定义添加**
1. 输入供应商名称（如「我的中转站」）。
2. ID 可留空，系统自动生成 `custom-xxxxxx`。
3. 填写 BaseURL（如 `https://api.xxx.com/v1`）和 API Key。
4. 选择协议：`openai`（默认，调用 `/v1/chat/completions`）或 `anthropic`（调用 `/v1/messages`）。

> 💡 顶部「🎁 注册送 Token」按钮列出了注册即送免费额度的供应商，可一键填充到表单。

### 5.2 拉取与测评模型

填好 BaseURL 和 API Key 后：

1. 点 **「⬇️ 拉取模型」**——OpenAI 协议会实时请求 `/models` 端点；Anthropic 协议没有标准模型列表，使用内置目录预置的模型清单。
2. 拉到的模型出现在候选列表，每行显示：
   - 模型 ID 和名称
   - 自动推断的能力标签（👁 视觉 / 🧠 推理 / 🔧 工具调用）
   - 上下文窗口大小、限流说明
3. 测评单模型：点该模型右侧「评测」，发送一个 256 token 的真实请求，成功显示 `✓ N tok/s`，失败显示 `✗ 失败`。
4. 批量测评：勾选多个模型 → 点「批量测评」→ 进度条显示 `done/total`，后端自动并发。
5. 加入模型：测评通过后点「加入」或「加入通过(N)」，模型才真正进入可用列表并参与降级链。

> 若在设置中开启了「进入编辑时自动拉取并测评模型」，打开供应商编辑时会自动完成这一整套流程。

```
拉取模型 ──► 候选列表 ──► 测评 ──► 加入可用
              │            │         │
              ▼            ▼         ▼
           全部模型     显示 tok/s   进入降级链
```

### 5.3 编辑与删除

- 卡片上点「编辑」进入表单；已通过的模型会保留。
- **API Key 保护**：自己添加的供应商，进入编辑时 Key 正常回显；从分享文件导入的供应商，Key 输入框留空（留空保存 = 保留原 Key；填入新值 = 覆盖并转为自有供应商）。
- 删除需二次确认，删除后其所有模型从降级链移除。
- 编辑中切换到其他供应商时，如果有未保存改动，会弹窗提示「保存并切换 / 放弃 / 取消」。

### 5.4 分享与导入（.sds）

供应商可以导出为加密的 `.sds` 文件，在不同设备 / 用户之间传递。

#### 导出分享

有两个入口：

- **顶部「🔗 分享/导入」**：弹出选择菜单，可选导出或导入。
- **单张卡片上的「🔗 分享」**：直接进入导出界面，并预勾选该供应商。

```
┌─ 📤 分享供应商 ────────────────────────────┐
│ 选择要分享的供应商（1/12）               │
│ ☑ api.agnes   3 模型                     │
│ ☐ Groq       8 模型                      │
│                                            │
│ ☑ 分享 API 密钥                            │
│   勾选后对方导入即可直接使用              │
│ ☑ 用密码保护                              │
│                                            │
│ 分享密码：[____________] [🎲 随机]        │
│ 留空则保存时自动生成 6 位随机码           │
│                                            │
│           [返回]  [💾 保存 .sds 文件]     │
└────────────────────────────────────────────┘
```

**两个选项：**
- **分享 API 密钥**：勾选后 `.sds` 内含你的真实 API Key，对方导入即可直接调用。⚠️ 含密钥时强制开启密码保护。
- **用密码保护**：
  - 不勾选（且不含密钥）：文件仍加密，但用内置密钥混淆，**对方导入无需密码**——适合只分享配置。
  - 勾选：用密码派生密钥真加密。可在输入框自定义密码，或点「🎲 随机」生成 6 位字母数字码（已去除易混字符 `0/O/l/1/I`）；留空则保存时自动生成。

保存成功后，若有密码，界面显示一次性密码，要求通过**另一个渠道**（微信 / 口头）发给接收方。

#### 导入

1. 顶部「🔗 分享/导入」→「导入」。
2. 选择 `.sds` 文件。
3. 若文件需要密码，输入密码解密；无密码自动解析。
4. 预览供应商列表，勾选要导入的。
5. 若 id 已存在，为每个冲突项选择策略：
   - **覆盖**：用导入的替换现有。
   - **跳过**：保留现有。
   - **重命名**：导入为 `原id-xxxxxx`。

导入的供应商卡片显示「来自分享文件导入」标签。不含 API Key 的分享，导入后模型需自行填入 Key 并重新测评（verified 会重置）。

### 5.5 主密码与锁定

为保护本地存储的供应商 API Key，Switch Dev 使用 argon2id + AES-GCM 加密。

**自动加密（默认）**
首次保存供应商时，系统自动生成随机主密码并存入系统钥匙串（macOS Keychain / Windows Credential Manager），无感加锁解锁。你无需记忆任何密码。

**设置主密码（可选）**
点供应商页右上角 🔐 → 设置主密码（至少 6 位）。设置后：
- 可勾选「在本机记住」将密码写入钥匙串，实现自动解锁。
- 系统生成一个 **24 位恢复码**（格式 `XXXXXX-XXXXXX-XXXXXX-XXXXXX`），只显示一次，请妥善保存。

**锁定与解锁**
- 设置主密码后，闲置 **5 分钟**自动锁定供应商界面（可在设置→通用中关闭）。
- 也可点锁图标 🔒 立即锁定。
- 锁定仅隐藏界面上的 Key，**不清内存、不影响代理转发**。
- 解锁输入主密码；忘记主密码可用恢复码重置并设新密码。
- 恢复码也丢失时，只能「销毁现有配置」——所有供应商和 Key 会被删除。

## 6. 内置上游凭据

「凭据」页显示 Switch Dev 探测到的内置上游状态。

每张卡片有三态：

| 状态 | 显示 | 操作 |
|------|------|------|
| 未安装 | 灰色「未安装」 | GUI 工具显示下载按钮；CLI 工具显示安装命令（可复制） |
| 已装未登录 | 黄色「已装未登录」 | 显示登录命令或登录页链接 |
| 有效 | 绿色「有效」 | 显示用户 ID / 昵称、Key 预览、过期时间、最近校验时间 |

| 上游 | 凭据来源 | 环境变量覆盖 |
|------|---------|-------------|
| JoyCode（京东云） | 从 `state.vscdb`（SQLite）读取 pt_key | `JOYCODE_VSCDB` |
| DevEco Code（华为） | `auth.json` 三层 AES-256-GCM 解密 | `DEVECO_AUTH_PATH` |
| WorkBuddy（腾讯） | `.info` 文件，含 refreshToken 自动续期 | `WORKBUDDY_INFO_PATH` |

- 点卡片上的「刷新」可立即重新检测。
- 后台每 10 分钟自动预检一次；凭据失效会自动尝试恢复（如 WorkBuddy 用 refreshToken 换新 token）。
- 路径全部跨平台自动探测，macOS 走 `~/Library/Application Support`，Linux 走 `~/.config`，Windows 走 `%APPDATA%`。

## 8. 运行模式与降级链

在「设置 → 运行模式」中配置模型路由策略。有三种模式：

### 8.1 auto 模式

客户端请求模型为 `auto`（或不指定模型）时，按你排的优先级链从上到下依次尝试，第一个成功的即返回：

```
请求 auto
   │
   ▼
DevEco/glm-5.1 ──失败──► JoyCode/Kimi ──失败──► OpenCode/deepseek ──失败──► 全局兜底
   │成功                 │成功                  │成功
   ▼                    ▼                     ▼
返回                  返回                   返回
```

- **添加**：在下拉中选上游 + 模型，加入链中。
- **排序**：点 ↑↓ 调整优先级。
- **移除**：点 ✕ 删除（5 秒内可撤销）。
- 凭据无效的上游自动跳过。
- 末尾自动追加**全局兜底**（去重），所有模型都失败时最后的保底。

### 8.2 manual 模式

客户端请求**具体模型名**时（如 `glm-5.1`），先打该模型本身；失败则按你为该模型单独配的降级链走；最后走全局兜底。

```
配置：
  glm-5.1  →  [wb/glm-5.1, deepseek-v4-flash-free]
  全局兜底 →  JoyCode/Kimi

请求 glm-5.1
   │
   ▼
DevEco/glm-5.1 ──失败──► wb/glm-5.1 ──失败──► deepseek-free ──失败──► Kimi
```

未单独配置降级链的模型，失败直接走全局兜底。

### 8.3 UA 路由模式

完全由请求的 `User-Agent` 决定走哪个模型。适合让不同客户端自动分流：

- 内置两条规则：`Claude Code`（UA 含 `claude-cli`）、`Codex`（UA 含 `codex`）。
- 每条规则由若干「请求模型 → 目标上游模型」映射组成。
- 未命中任何规则的请求走 **UA 兜底**。

UA 路由在 auto / manual 模式下也可作为叠加层开启（默认开启）：命中 UA 规则的目标会被插到链首。

### 8.4 方案（Preset）

方案是当前运行模式四要素的**命名快照**：

- 模式（auto / manual / ua）
- 对应的降级链配置
- 全局兜底 / UA 兜底
- UA 规则

```
┌─ 方案 ────────────────────────────┐
│ [日常使用 ▼]  [💾 保存为方案]      │
│   日常使用                         │
│   全免费                           │
│    coding 专用                     │
│   ─────────                        │
│   重命名... / 删除...              │
└───────────────────────────────────┘
```

- **保存方案**：把当前配置存成一个名字。
- **切换方案**：从下拉选，立即生效。
- **快照语义**：切换后再修改配置不会自动回写方案，需再次同名保存。下拉会显示「自定义」提示当前已偏离。
- 方案不含端口 / apiKey / 更新设置（那些是环境配置，不应随方案切换）。

托盘菜单的「方案」子菜单也可以快速切换。

## 9. 接入客户端

代理起来后，把客户端的 baseURL 指向 `http://127.0.0.1:8787`。

**Claude Code** — 编辑 `~/.claude/settings.json`：
```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:8787",
    "ANTHROPIC_AUTH_TOKEN": "rs-你的apiKey",
    "ANTHROPIC_MODEL": "auto"
  }
}
```

**Codex** — 编辑 `~/.codex/config.toml`：
```toml
model = "auto"
model_provider = "switchdev"
[model_providers.switchdev]
base_url = "http://127.0.0.1:8787/v1"
wire_api = "chat"
```

**cc-switch**：添加供应商，baseURL 填 `http://127.0.0.1:8787`，apiKey 填仪表盘显示的值，模型填 `auto` 或具体模型 ID。

**鉴权头格式**（其他客户端）：
```
x-api-key: rs-你的apiKey
```
或
```
Authorization: Bearer rs-你的apiKey
```

> 如果在设置中关闭了 apiKey 鉴权，则无需携带任何 key，仅适用于受信任的本地环境。**切勿把 8787 端口暴露到公网。**

**支持的端点**

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/`、`/health` | 健康检查（无需鉴权） |
| GET | `/v1/models` | 模型列表 |
| POST | `/v1/messages` | Anthropic Messages API |
| POST | `/v1/chat/completions` | OpenAI Chat Completions |
| POST | `/v1/responses` | OpenAI Responses API |

流式（SSE）全部支持：非流式上游由代理在本地拆成 SSE 事件下发，体验一致。

## 13. 设置

### 13.1 通用

**代理端口**
- 默认 `8787`，范围 1024–65535。
- 改完点「💾 保存端口」，代理会重启。

**接入 apiKey**
- 开关控制是否要求客户端鉴权（默认开启）。
- 开启时：
  - 显示当前 key（掩码 / 明文切换）、复制按钮。
  - 「🔄 重新生成」会创建新的 `rs-<uuid>`，旧 key 立即失效，所有客户端需更新（二次确认）。
- 关闭时：网关不校验任何 key，仪表盘也不显示 key 行。

**供应商配置**
- 进入编辑时自动拉取并测评模型（默认关闭）。
- 闲置 5 分钟自动锁定供应商界面（默认开启，仅在设置了主密码时生效）。

**日志文件**
- 默认开启，把控制台输出写入 `logs/YYYY-MM-DD.log`。
- 7 天前压缩为 `.gz`，90 天前删除。

### 13.2 费率

维护模型单价表（美元 / 百万 token）：

- 字段：模型 ID、显示名、输入价、输出价、缓存读价、缓存写价。
- 内置一份默认费率，可搜索、增删改。
- 「同步」从 GitHub 拉取最新默认费率（会覆盖本地修改，需二次确认）。

仪表盘和统计中的费用估算都基于此表。

### 13.3 更新

- 显示当前版本。
- 启动后 3 秒首次检查，之后每 6 小时检查 GitHub Releases。
- **强制更新**：版本 major 或 minor 段变化（如 0.0.x → 0.1.0），弹窗不可忽略。
- **可选更新**：仅 patch 段变化，可稍后。
- 点「立即更新」下载对应平台二进制并原子替换，完成后提示重启。
- 更新日志取自 GitHub Release body。

**关于页**：显示 Logo、版本、技术栈（Wails v3 + Go + React），点击 Logo 跳 GitHub。

## 16. 常见问题

**Q：启动后仪表盘显示所有上游都无效？**
前往「凭据」页确认至少安装并登录了一个工具。CLI 工具可用页面提供的命令安装；装完无需重启 Switch Dev，后台会自动探测。

**Q：auto 模式总是降级到兜底模型？**
查看「日志」页的错误信息。常见原因：上游 token 过期（重新登录对应工具）、免费额度耗尽、模型名变更（点「刷新模型」）。

**Q：改了端口后客户端连不上？**
客户端的 baseURL 端口必须同步修改。代理重启需要一两秒。

**Q：apiKey 忘了 / 想重置？**
在「设置 → 通用 → 接入 apiKey」点「重新生成」，旧 key 立即失效。也可以关闭鉴权（不推荐暴露到非本机网络）。

**Q：分享的 .sds 文件对方导入后无法调用？**
如果分享时未勾选「分享 API 密钥」，对方需要自己编辑供应商填入 Key 并重新测评。含密钥的分享，确认密码输入正确。

**Q：主密码忘了怎么办？**
用设置主密码时获得的 24 位恢复码重置。恢复码也丢失只能「销毁现有配置」，供应商全部删除后重新添加。

**Q：代理会把我的数据发到哪里？**
请求只发往各上游官方 API（你登录的那几个工具的服务器、以及你配置的供应商 baseURL）。用量统计和日志仅存本地。唯二的外联是：启动时检查 GitHub Releases 是否有新版本、拉取免费供应商目录。

**Q：能用来给团队 / 公司共用吗？**
可以，但有两点要注意：1) 代理默认只监听 `127.0.0.1`，若要局域网共用需自行做反代并务必开启 apiKey 鉴权；2) 内置上游的登录态绑定你个人账号，共用等于共享你的账号额度，请遵守各工具的服务条款。代码本身以 MIT 协议开源，允许商用。
